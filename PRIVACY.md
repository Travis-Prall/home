# Privacy Policy

**Effective date:** September 27, 2026
**Last updated:** September 27, 2026

This repository, `Travis-Prall/home`, and any static page published from it are operated by Travis Prall ([@Travis-Prall](https://github.com/Travis-Prall)). This policy explains what this project does with personal data. It describes the project itself, not the third party services it links to.

## Summary

- This project collects no personal data.
- It sets no cookies, runs no analytics, and includes no trackers, advertising, or forms.
- GitHub hosts the repository and processes the technical data described in GitHub's own privacy statement.
- Donations are handled entirely by Buy Me a Coffee or GitHub Sponsors if you choose to use them.

## What this project collects

Nothing. This repository contains text files only: a README, a license, this policy, and editor and Git configuration files. There is no application code, no server, no database, no web form, and no user accounts. The project therefore does not collect, store, process, or share personal data, and it does not set cookies or use local storage, analytics, session recording, advertising identifiers, or tracking pixels.

## What GitHub processes

GitHub hosts this repository and serves every page of it. When you view the repository, open an issue, or otherwise interact with it, GitHub may process technical and account data such as your IP address, browser and device information, request timestamps, and, if you are signed in, your GitHub account details and public activity. That processing is carried out by GitHub as the hosting provider under the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), not by this project.

Anything you post in a public place, such as an issue or a comment, becomes public. Please do not include personal or sensitive information in an issue.

If a static site is published from this repository later, for example through [GitHub Pages](https://docs.github.com/en/pages), it will be served by GitHub in the same way, and this policy will still apply to the project's own behavior: no cookies, no analytics, and no tracking.

## Donations

The README links to two optional funding services. Payment details are never seen or stored by this project.

- [Buy Me a Coffee](https://www.buymeacoffee.com/travisprall) processes your payment and account information under the [Buy Me a Coffee privacy policy](https://www.buymeacoffee.com/privacy-policy).
- [GitHub Sponsors](https://github.com/sponsors/Travis-Prall) processes payments through GitHub under the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and the [GitHub Sponsors Additional Terms](https://docs.github.com/en/site-policy/github-terms/github-sponsors-additional-terms).

In each case the operator receives only what the platform chooses to share, such as a display name, the donation amount, and any message you include. Donations are always optional.

## Links to other sites

This project links to other websites and services. Their privacy policies apply once you follow a link, and this policy does not cover how they handle your data.

## Children's privacy

This project is not directed to children and collects no personal data from anyone, including children under 13.

## Retention

This project retains no personal data, because it collects none. Data held by GitHub, Buy Me a Coffee, or GitHub Sponsors is retained according to their own policies.

## Your rights and choices

Because this project collects no personal data, there is nothing for it to show, correct, export, or delete. To exercise privacy rights against a third party service, contact that service directly using the links above. The project does not sell or share personal data, because it holds none.

## Security

No personal data is stored by this project, so there is no project side store to breach. If you believe you have found a security problem in this repository, please open an issue.

## Changes to this policy

This policy may be updated if the project changes, for example if a landing page is added or its behavior changes. The effective date at the top will be updated, and this repository's commit history records every revision.

## Contact

Questions about this policy? [Open an issue](https://github.com/Travis-Prall/home/issues) on this repository. Issues are public, so please do not include sensitive information. The operator can also be reached through the [GitHub profile](https://github.com/Travis-Prall).
